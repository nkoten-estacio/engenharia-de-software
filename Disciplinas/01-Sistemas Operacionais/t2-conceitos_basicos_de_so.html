Sistemas operacionais

evolucao

  1. batch processing
  2. multiprogramacao

tipos de SO

  • sistemas monoliticos: kernel unico, codigo compartilhado
  • sistemas modulares: kernel modular, drivers separados
  • sistemas distribuidos: recursos compartilhados em multiplos computadores

Estrutura basica

  1. kernel: nucleo do sistema
  2. chamadas de sistema: interface entre aplicacoes e kernel
  3. gerenciamento de processos: criacao, termino, escalonamento
  4. gerenciamento de memoria: alocacao, organizacao, protecao

Linux

  1. servidores: web, bd, email
  2. pcs pessoais: ubuntu, fedora
  3. dispositivos embarcados: android, iot

conceitos

  • processos: programas em execucao
  • threads: unidades de execucao dentro de um processo
  • sincronizacao: coordenacao entre processos e threads
  • comunicacao: troca de dados entre processos

formas de pensar em sistema operacional

  • voltado para interface grafica sistemas que vao rodar nos pcs

  • rodar codigo o mais rapido possivel e otimizar a execucao de recursos

    arquiteturas distribuidas: multiplos pcs que rodam o mesmo SO arquiteturas monoliticas: mega pcs que vao rodar o SO

kernel

nucelo do sistema operacional

faz interface com todos os componentes de hardware do sistema computacional

funcionalidade

  1. gerenciamento de processos

    cria, executa e termina processos

  2. gerenciamento de memoria

    aloca e desaloca memoria para processos

  3. gerenciamento de dispositivos

    controla o acesso do dispositivo

  4. gerenciamento de arquivos

    controla o acesso, organiza os srquivos

Modos de Acesso

Modo Kernel kernel opera com acesso total ao hardware e aos recursos do sistema

Modo Usuário aplicações e programas opera, acesso limitado, impedidos de acessar diretamente o hardware

gerenciamento de memória e acesso a recursos

  1. faz alocação e desalocação de memória para os processos
  2. gerencia os dispositivos de hardware para que os recursos sejam utilizados corretamente
  3. controla o acesso de arquivos para quem tem ou não permissão

Escalonamento de Processos e Threads

  1. Planejamento de qual processo tem que ser executado
  2. é escalonado, a execução daquele processo é priorizada
  3. o gerenciamento de threads é feito dentro desse mesmo processo

Comunicação entre processos e Sincronização

  • mensagem processos compartilham dados e coordenem suas ações
  • sincronização o sistema tem que fornecer mecanismos para sincronizar o acesso aos recursos compartilhados, e evitar conflitos de de processos diferentes acessarem os mesmos dados
  • semáforos Estrutura de dados que controla os recursos que são compartilhados e garantem que só um processo por vez tenha acesso ao recurso
  • mutex mecanismo de exclusão mútua, permite que apenas um processo por vez tenha acesso ao recurso

Virtualização e Isolamento de Ambientes

  • Virtualização implementação de um programa "o virtualizador" rodando em modo kernel em cima do SO
  • Contêiners separa um pedaço da memória, que só pode ser acessado por esse contêiner
  • Nuvem milhares de hardwares rodando um SO multiescalável compartilhado em rede, com virtualização rodando e conteinerização
